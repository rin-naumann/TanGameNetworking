# GAME NETWORKING MIDTERMS

Game Name: One Shot

Game Link (via Unity Play): https://play.unity.com/en/games/4a652714-9abf-40f1-a544-af0034010ca6/onetap

Github Repository: https://github.com/rin-naumann/TanGameNetworking/tree/midterm_ver

This game is a 1v1 arena sniper duel focused on movement. To win, you must score more points than your opponent. Points are obtained by getting kills.

Controls:
- WASD | Movement
- Q | Grapple
- L. Shift | Dash
- L. Ctrl | Run
- R. Click (Hold) | ADS
- L. Click | Shoot

Known Issues:
- Must reload page to replay the game.
- Certain movement bugs.
- No settings to change sensitivity or sound volume.
- No BGM.
